# Ferramentas do Engenheiro

Calculadoras e simulados gratuitos para engenheiros, técnicos e estudantes: https://ferramentasdoengenheiro.com

- `docs/` — site publicado (GitHub Pages, domínio próprio via `docs/CNAME`).
- `src/build_site.py` — gera o site a partir dos posts em `src/posts/`.
- `src/questoes/` — banco de questões inéditas (estilo Cesgranrio) e gerador do simulado.
